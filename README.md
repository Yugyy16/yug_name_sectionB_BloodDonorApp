## 🩸 Project Description
The **Blood Donor App** is a Flutter-based mobile application designed to connect blood donors and recipients in real-time. It allows users to register as donors, search for blood types nearby, and request donations when needed. The app is built with simplicity and usability in mind, making it easier to save lives through timely blood donations.

## 🚀 Technologies Used
- **Flutter** (UI toolkit)
- **Dart** (Programming language)

## 📱 Features
- Register as a blood donor
- Search for donors by blood type
- Request blood donations
- Clean and user-friendly UI
- Future-ready for integration with real-time databases and notifications
